# Samboryk OS

Дистрибутив Linux на базі **Kubuntu 26.04 LTS** (KDE Plasma 6.6) у скляному стилі «Graphite».
Поточна версія — `0.1.0~alpha1`, канал **alpha**.

## Що всередині

| Пакет | Що робить |
|---|---|
| `samboryk-branding` | Назва й логотип системи, екран завантаження, екран входу, команда `samboryk-channel` |
| `samboryk-theme` | Глобальні теми Silver (світла) і Graphite (темна), кольорові схеми з червоним акцентом, шпалери, заставка входу, верхня панель + плаваючий док |
| `samboryk-icons` | Значки в стилі macOS — [WhiteSur](https://github.com/vinceliuice/WhiteSur-icon-theme) (GPL-3.0), без логотипа Apple |
| `samboryk-archive-keyring` | Канал оновлень: адреса репозиторію й ключ, яким підписані оновлення |
| `samboryk-desktop` | Збирає все разом і тягне Steam, Wine, Lutris, GameMode, MangoHud, KDE Connect, Timeshift, Discover |

Образ ISO — це офіційний Kubuntu з цими пакетами всередині. Встановлюється звичайним інсталятором Kubuntu (Calamares).

## Структура

```
VERSION                     номер версії
packages/<пакет>/           вміст пакетів (root/ — файли, debian/ — опис і скрипти)
tools/build-debs.sh         зібрати .deb-пакети
tools/build-repo.sh         оновити репозиторій оновлень
tools/make-key.sh           створити ключ підпису (один раз)
tools/render-assets.py      перемалювати логотип і шпалери
tools/gen-colors.py         перегенерувати кольорові схеми
iso/build-iso.sh            зібрати ISO
iso/customize-chroot.sh     що робиться всередині образу
.github/workflows/          автоматичне збирання на GitHub
```

## Перший запуск (один раз)

1. **Створіть репозиторій на GitHub**, наприклад `samboryk-os`, і завантажте туди всі файли.
2. **Створіть ключ підпису оновлень.** На Windows відкрийте Git Bash у папці проєкту:
   ```
   bash tools/make-key.sh
   ```
   Скрипт створить два файли в `keys/`:
   - `samboryk-archive.asc` — публічний ключ, його треба закомітити;
   - `PRIVATE-samboryk-archive.asc` — приватний. Скопіюйте весь його текст у GitHub:
     **Settings → Secrets and variables → Actions → New repository secret**,
     назва `SAMBORYK_GPG_PRIVATE_KEY`. Після цього файл видаліть.

   Ключ створюється один раз. Якщо його загубити, вже встановлені системи перестануть отримувати оновлення.
3. **Опублікуйте перші пакети:** вкладка **Actions → Оновлення → Run workflow**.
   Пакети ляжуть у гілку `gh-pages`, і системи братимуть їх звідти за адресою
   `https://raw.githubusercontent.com/<логін>/samboryk-os/gh-pages/apt` (GitHub Pages вмикати не потрібно).
4. **Зберіть ISO:** **Actions → Збірка ISO → Run workflow**. Це займає 1–2 години.
   Готовий образ з'явиться в **Releases**, розбитий на частини по 1,9 ГБ
   (GitHub не приймає файли більші за 2 ГБ). Як склеїти — написано в описі релізу.

## Як працюють оновлення

```
ви змінюєте файли → піднімаєте VERSION → push
        ↓
GitHub Actions збирає пакети й підписує їх ключем
        ↓
GitHub роздає репозиторій з гілки gh-pages
        ↓
у всіх користувачів Discover показує «Доступні оновлення»
```

Оновлення Ubuntu (ядро, браузер, драйвери) приходять як звичайно — з серверів Ubuntu.
З вашого репозиторію приходять тільки пакети `samboryk-*`.

**Випустити оновлення:**
1. Змініть, що потрібно, в `packages/`.
2. Підніміть номер у файлі `VERSION`: `0.1.0~alpha1` → `0.1.0~alpha2`.
3. Push у гілку `main` — workflow «Оновлення» запуститься сам і опублікує в канал **alpha**.
   Щоб опублікувати в інший канал, запустіть його вручну й оберіть канал.

Порядок версій: `0.1.0~alpha1` < `0.1.0~alpha2` < `0.1.0~beta1` < `0.1.0`.
Знак `~` означає «раніше за реліз», тож альфи й бети завжди старші за фінальну версію.

**Канали.** Кожна система підписана на один канал. Змінити канал на встановленій системі:
```
samboryk-channel beta      # або alpha / stable
samboryk-channel           # показати поточний
```

## Локальне збирання (Ubuntu або WSL2)

```
sudo apt install xorriso squashfs-tools apt-utils git curl
REPO_URL=https://raw.githubusercontent.com/<логін>/samboryk-os/gh-pages/apt tools/build-debs.sh
sudo -E iso/build-iso.sh
```
Потрібно ~30 ГБ вільного місця. Скрипт сам знайде й завантажить свіжий образ Kubuntu 26.04
та перевірить його контрольну суму.

## Тестування

Перші версії пробуйте у VirtualBox: 4–8 ГБ пам'яті, 40 ГБ диска,
**Дисплей → Відеопам'ять 128 МБ, увімкнути 3D-прискорення** (без нього не буде розмиття й прозорості).

## Що вже є в альфі

- назва, логотип, «Про систему», екран завантаження і входу;
- світла й темна теми, червоний акцент (змінюється в Параметрах системи → Кольори);
- верхня панель із глобальним меню, плаваючий док, кнопки вікон зліва;
- значки WhiteSur, шпалери Samboryk Glass (світлі й темні);
- Steam (з Proton), Wine, Lutris, GameMode, MangoHud;
- KDE Connect (телефон ↔ комп'ютер), Timeshift (знімки системи);
- канал оновлень alpha/beta/stable.

## Що далі (бета)

- скляне оформлення самих вікон (тема Kvantum);
- «Простори» (Навчання / Робота / Гра / Відпочинок) — перемикач і автоматичні налаштування;
- «Пульс» — капсула вгорі екрана з музикою, таймером і завантаженнями;
- майстер першого запуску;
- власна сторінка завантаження й новин проєкту.
